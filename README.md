# Denta Tracker — версия 1

Первая мобильная PWA-версия для iPhone.

## Что уже работает
- Стартовая анкета и профиль.
- Главная: калории, вода, шаги, вес.
- Дневник питания по категориям.
- Избранные блюда.
- Редактирование норм и темы.
- Календарь записей.
- Таблица статистики (по доступным сохранённым данным).
- Экспорт/импорт JSON-резервной копии.
- Локальное хранение в браузере.

## Публикация бесплатно через GitHub Pages
1. Создайте публичный репозиторий `denta-tracker`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. В репозитории откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите `main` и `/ (root)`, затем Save.
6. После публикации откройте адрес GitHub Pages в Safari на iPhone.
7. Нажмите «Поделиться» → «На экран Домой».

## Важно
- Данные хранятся локально в браузере на устройстве.
- Экспортируйте резервную копию регулярно и храните её отдельно.
- Удаление данных Safari или потеря устройства может привести к потере данных без резервной копии.
- В этой версии пока нет автоматической облачной синхронизации и фоновых напоминаний.
- Это прототип для личного трекинга, а не медицинское приложение.
